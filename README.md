# EduTrack

EduTrack is a student management system designed to streamline the process of managing student records. It provides a backend API built with Node.js and Express, and a frontend built with React.

## Features

- **Authentication**: Google OAuth-based login for secure access.
- **Student Management**: Add, edit, delete, and search for student records.
- **Search Functionality**: Filter students by name or roll number.
- **Responsive Design**: User-friendly interface for managing student data.

## Project Structure

### Backend
The backend is built with Node.js, Express, and MongoDB.

#### Key Features:
- RESTful API for managing students and authentication.
- MongoDB database integration using Mongoose.
- Middleware for authentication and error handling.
